SOVARA GIVEAWAY v0.9 — циклические розыгрыши

Что добавлено:
- Раунды розыгрыша (#1, #2, ...).
- Автоматический старт 30-дневного периода после 10 подходящих участников.
- После окончания таймера начисление баллов/билетов замораживается.
- Победителя нельзя выбрать раньше окончания таймера даже прямым API-запросом.
- Выбор победителя по билетам через crypto.randomInt.
- При выборе победителя сохраняется неизменяемый снимок Twitch, баллов, билетов, подарка и контактов.
- После определения победителя редактирование профиля блокируется до нового раунда.
- Кнопка «Приз выдан».
- Кнопка «Завершить розыгрыш» с сохранением в историю.
- Кнопка «Новый розыгрыш».
- Новый раунд сбрасывает points/tickets/watchtime текущего раунда у всех пользователей.
- Профиль, подарок, Steam/Ozon/игровые данные, Telegram/VK сохраняются.
- ЧС победителей и 24-часовые блокировки не сбрасываются новым раундом.
- История завершённых розыгрышей доступна только в админке и хранит снимок данных победителя.
- HOST теперь поддерживается штатно; на VPS приложение может слушать 127.0.0.1 без ручного sed.

ВАЖНО ДЛЯ VPS
Живое состояние находится в /var/lib/sovara-giveaway и обновлением GitHub НЕ перезаписывается.
Файлы data/ внутри репозитория — только стартовый шаблон для новой установки.

После загрузки v0.9 в GitHub на VPS:

cd /opt/sovara-giveaway
git fetch origin
git reset --hard origin/main
npm install --omit=dev
systemctl restart sovara-giveaway
systemctl --no-pager --full status sovara-giveaway
curl -sS http://127.0.0.1:4177/api/status

Почему reset --hard: в v0.7 на VPS server.js вручную менялся через sed. v0.9 уже умеет HOST=127.0.0.1 из /etc/sovara-giveaway.env, поэтому старая локальная правка больше не нужна.
