SOVARA GIVEAWAY v1.2

Что добавлено:
- Владелец SOVARA может назначать и снимать дополнительных администраторов по Twitch-логину.
- Дополнительные администраторы получают доступ к админке: участники, баллы, блок активности, ЧС победителей, история и управление текущим розыгрышем.
- Только владелец может управлять списком администраторов и переподключать Twitch-службы.
- Владелец и дополнительные администраторы исключаются из начисления баллов, билетов и пула победителей.
- После снятия роли доступ к админским API пропадает сразу, даже если сессия пользователя ещё открыта.
- Логотип SOVARA GIVEAWAY в шапке нельзя выделить мышкой.
- Добавлен favicon (SVG + ICO) в стилистике совы SOVARA.
- Добавлена кнопка Twitch в шапке. При подключённых Twitch-службах показывает LIVE/OFFLINE и ведёт на twitch.tv/sovara_.

Обновление VPS после загрузки содержимого архива в GitHub:

cd /opt/sovara-giveaway
git fetch origin
git reset --hard origin/main
npm install --omit=dev
systemctl restart sovara-giveaway
systemctl --no-pager --full status sovara-giveaway
curl -sS https://gift.sovara.ru/api/status

Живые данные находятся в /var/lib/sovara-giveaway и обновлением кода не перезаписываются.
